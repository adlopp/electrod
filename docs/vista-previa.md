# Vista previa publicada

`index.html` en la raíz del repo es la **maqueta de muestra** (no la web
definitiva) que se enseñó al amigo para validar el estilo antes de construir el
sitio completo con Astro descrito en el plan. Se publica vía GitHub Pages desde
la rama `main`.

Cuando arranque la Fase 2 del plan (proyecto Astro real), este `index.html`
estático se sustituye por el output del build de Astro y este fichero de nota
se puede borrar.
